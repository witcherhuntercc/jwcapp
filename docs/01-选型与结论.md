# Web → App 选型与结论

> 评估时间：2026-10-15 ｜ 被测样本：一个 Vue 3.5 + Vite 8 + Element Plus 的 SPA（原本网页端，已做过手机样式适配）
> 数据均为本机实测。

---

## 〇、决策（本库采用）

**采用 Capacitor**（`ionic-team/capacitor`，实测 **8.5.3**）。理由与数据见下文；未被采用的三个候选（Tauri v2 / Bubblewrap-TWA / HBuilderX-DCloud）的排除依据也在下文一一列出。

---

## 一、结论

| 排序 | 方案 | 结论 |
|:---:|------|------|
| **①主推** | **Capacitor**（ionic-team/capacitor） | 与"标准 / 开源 / 长期可维护 / 能扩原生能力"最匹配；本机已完整跑通并装真机 |
| ②备选 | HBuilder X + DCloud 离线打包 SDK | 工具链最全、当天可出包；缺点是封闭生态，原生能力受 DCloud 插件限制 |
| ③暂不选 | Tauri v2 Mobile | 体积最小但要 Rust + NDK（本机完全没有）；收益不是痛点 |
| ④排除 | Bubblewrap / TWA | 由**设备上的 Chrome** 渲染、分发依赖 Google Play → 国内机型结构性不适用 |

---

## 二、四方案对照

| 维度 | Capacitor | HBuilderX+DCloud | Tauri v2 | Bubblewrap(TWA) |
|------|-----------|------------------|----------|-----------------|
| 开源/生态 | 国际主流，插件最全 | 国内生态，uni-app / 5+App | 新兴，移动插件较少 | Google 官方 CLI |
| 本机就绪度 | 差 3 项环境配置（已解决） | ✅ 全部现成 | ❌ 无 Rust 工具链 | ❌ 需 JDK8 + cmdline tools |
| 出包体积 | **6.39 MB**（实测；web 产物 5.63MB） | 视配置，一般 10MB+ | 最小 | 最小（无内核） |
| 原生能力 | 官方插件：推送/生物识别/相机… | uni-push（国内送达好） | 较少 | 受 TWA 限制 |
| 国内分发 | ✅ 直接 sideload APK | ✅ | ✅ | ❌ 依赖 Play/Chrome |
| 前端改动 | **零**（容器包裹） | 需重写到 uni-app 组件体系，或走 5+App 套壳 | 零 | 需满足 PWA + assetlinks |

> 关键区别：**uni-app 不是套壳，是把项目重写到它的组件体系**（对纯 Vue SPA 改造成本高）；HBuilderX 的 **5+App / wap2app** 才是套壳路线。

---

## 三、为什么排除 TWA（Bubblewrap）

- TWA 的本质是"给 Chrome 一个壳"：页面由**设备上的 Chrome** 渲染，App 自身不含内核。
- 分发走 Google Play（AAB）；国内机型普遍没有 Play/Chrome → 装了打不开或退化成浏览器标签页。
- 还需在站点根发布 `assetlinks.json`（数字资产声明）才不显示地址栏。
- 它自己的 README 要求 **JDK 8** + Android cmdline tools（"省事"的反面）。

**它是最优解的场景**：用户主要在**海外 Android + Google Play** 分发。

## 四、Capacitor 实测记录（本机）

| 步骤 | 命令 / 对象 | 结果 |
|------|------------|------|
| 装核心包 | `npm i @capacitor/{core,cli,android}`（npmmirror） | 98 包 / **24 秒** |
| 初始化 | `npx cap init "Name" "com.example.app" --web-dir=www` | 生成 `capacitor.config.json` |
| 喂产物 | 前端 `dist`（134 文件 / 5.63 MB）→ `www` | 含 manifest、sw.js、图标 |
| 生成原生工程 | `npx cap add android` | **1 秒**，并自动把 web 产物拷进 `android/app/src/main/assets/public` |
| 工程参数 | `variables.gradle` | minSdk **24** / compileSdk **36** / targetSdk **36**；AGP **8.13.0**；Gradle **8.14.3** |
| 出包 | `gradlew assembleDebug` | **37 秒**（依赖已缓存），产出 **6.39 MB** APK |
| 权限 | `aapt2 dump badging` | 仅 `INTERNET`（+ Capacitor 自用权限） |
| 签名 | `apksigner verify` | Android Debug 证书，可直接 sideload |

## 五、原生能力对照（决定长期选型）

| 能力 | Capacitor | HBuilderX/DCloud | Tauri |
|------|-----------|------------------|-------|
| 推送通知 | `@capacitor/push-notifications`（Android 走 **FCM**） | uni-push（国内厂商通道，送达省心） | 少 |
| 生物识别 | `@capacitor/biometric-auth` | 有 | 少 |
| 相机/文件/剪贴板/震动 | 官方插件齐全 | 齐全 | 少 |

> 目标用户在中国大陆时，**推送要先比较 FCM 与厂商通道/uni-push 的实际送达率再定**，不要先绑死一个体系。
