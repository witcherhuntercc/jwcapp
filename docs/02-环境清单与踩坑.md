## 二、踩坑清单（现象 → 根因 → 修法）

### 坑 1：`错误: 无效的源发行版：21`（JDK 版本）

- **现象**：`gradlew assembleDebug` 失败在 `:capacitor-android:compileDebugJavaWithJavac`，报 `Java compilation initialization error`；中文 Windows 下错误信息是 GBK 乱码。
- **根因**：AGP 8.13 只要求 JDK 17，但 **Capacitor（实测 8.5.3）的 android 库声明 `sourceCompatibility JavaVersion.VERSION_21`**。JDK 17 编译不了 21 的目标。
- **修法**：装 JDK 21 并让构建用 21。注意 **HBuilderX 自带的 Corretto 是 17，不够用**。

### 坑 2：Gradle 发行包下载要 2.4 小时

- **根因**：`gradle-wrapper.properties` 默认指向 `services.gradle.org`，实测 15 KB/s。
- **修法**：改 `distributionUrl` 指向腾讯镜像，**官方 URL 写在旁边注释里作回退**：

```properties
# 官方源保留作回退：https\://services.gradle.org/distributions/gradle-8.14.3-all.zip
distributionUrl=https\://mirrors.cloud.tencent.com/gradle/gradle-8.14.3-all.zip
```

### 坑 3：Maven 依赖慢

- **修法**：`build.gradle` 的两个 `repositories` 块里，**镜像放前面、官方保留在后面**（Gradle 按顺序尝试，等价于"镜像优先 + 官方兜底"）：

```gradle
repositories {
    maven { url 'https://maven.aliyun.com/repository/google' }
    maven { url 'https://maven.aliyun.com/repository/public' }
    google()
    mavenCentral()
}
```

### 坑 4：手机端登录/注册报 **403 「没有权限访问」**（最坑的一个）

- **现象**：网页/App 里登录、注册都失败，`Request failed with status code 403`；直接 curl 同一个接口却是 200。
- **根因**：**后端 CORS 白名单里没有这个对外域名**。浏览器与 WebView 的 POST 会带 `Origin` 头，Spring 发现 Origin 不在 `CORS_ALLOWED_ORIGINS` 里 → 直接 403 且响应体为空。
- **定位方法**（决定性）：同一条请求带与不带 Origin 各发一次：

```powershell
# 不带 Origin → 200（业务层响应）
# 带 Origin: https://你的域名 → 403（空体）＝ CORS 拒绝
```

- **修法**：把公网域名加进后端 `.env` 的 `CORS_ALLOWED_ORIGINS`，重启后端。

### 坑 5：手机端头像/附件全部裂图

- **根因**：`MINIO_CUSTOM_DOMAIN=http://127.0.0.1:9000/jwcfast` 会被写进 MinIO 生成的资源 URL；**手机上的 `127.0.0.1` 指手机自己**。
- **修法**：改成同源相对路径 `MINIO_CUSTOM_DOMAIN=/jwcfast`，由网关（Nginx/隧道）代理；**同时要给桌面开发服务器加上 `/jwcfast` 代理**，否则桌面端会受影响。

### 坑 6：前端构建报 `workbox-window` 找不到

- **现象**：`vite build` 失败：`Rolldown failed to resolve import "workbox-window" from "/@vite-plugin-pwa/virtual:pwa-register"`。
- **根因**：`vite-plugin-pwa` 的注册模块需要 `workbox-window`，但宿主项目没显式声明它（包可能已在 store 里，只是没链接到顶层）。
- **修法**：`pnpm add -D workbox-window`（或 npm 等价命令），让它进 `package.json` + lockfile。
- **临时救急**（不改 package.json）：把 store 里的目录联接出来：
  `node_modules\workbox-window` → `node_modules\.pnpm\workbox-window@7.4.1\node_modules\workbox-window`

### 坑 7：WebView 里页面白屏、控制台 `Blocked request. This host is not allowed.`

- **根因**：**不是隧道问题**，是前端开发服务器（Vite）自己的 Host 白名单：`server.allowedHosts` 只放行了 localhost/已知域名。
- **修法**：把新域名加进 `vite.config.ts` 的 `allowedHosts`；或在网关层把 Host 改写成白名单内的值（`proxy_set_header Host 127.0.0.1:3000`）。

### 坑 8：APK 里看到的不是你的应用，而是别的页面

- **根因**：`capacitor.config.json` 里的 `server.url` 会**覆盖**内置产物。
- **检查**：拆开 APK 看 `assets/capacitor.config.json` 与 `assets/public/index.html` 是否都在；`server.url` 指向哪里，App 就加载哪里。

### 坑 9：`.ps1` 带中文就报语法错

- **根因**：Windows PowerShell 5.1 按 GBK 解码无 BOM 的 UTF-8 脚本。
- **修法**：脚本存为 **UTF-8 with BOM**，或统一用 `pwsh`（PowerShell 7）运行。
