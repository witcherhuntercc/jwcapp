# 实测记录（2026-10-15 首次打通全链路）

> 记录一次真实的"从 0 到手机上能用的 App"的过程，包含构建、部署、以及三个真实故障的定位与修复。

---

## 一、构建阶段

| 环节 | 结果 |
|------|------|
| 容器与依赖 | `npm i @capacitor/{core,cli,android}`（npmmirror）98 包 / 24 秒 |
| 生成原生工程 | `npx cap add android` **1 秒**，web 产物自动拷入 |
| 首次构建 | **失败**：`错误: 无效的源发行版：21`（JDK 17 → 需 21） |
| 装 JDK 21 | 华为云镜像 192MB / **9 秒** |
| 二次构建 | **成功 37 秒**，产出 **6.39 MB** APK |
| 验收工具 | `aapt2 dump badging`（包名/权限/label）、`apksigner verify`（debug 签名有效） |
| 一键重建脚本 | 增量构建 **1 秒** |

**APK 实测参数**：包名 `com.jwcfast.app`、minSdk 24 / targetSdk 36、权限仅 `INTERNET`、签名 Android Debug。

## 二、上线阶段（让手机看到"真实应用"而不是演示页）

**背景**：首版 APK 的 `server.url` 指向隧道域名，而该域名当时指向的是隧道自带的演示静态页 → 手机上看到的是"服务在线"页。

**采用方案**：不动 Cloudflare、不重打 APK，把隧道回源端口（8080）从演示页换成**反向代理网关**：

| 步骤 | 动作 |
|:---:|------|
| 1 | 起基础设施：MySQL(3306) / PostgreSQL(5432) / Redis(6379) / MinIO(9000)（后台分离启动） |
| 2 | 起 Java 后端(8889)、jwcai(8890) |
| 3 | 重建前端产物（`npm run build`） |
| 4 | 停用演示页任务，释放 8080 |
| 5 | 用 Nginx 在 8080 托管前端产物 + 反代 `/api`、`/ws`、`/jwcfast` |

**验证证据**：

| 检查 | 结果 |
|------|------|
| 公网 `https://<域名>/` | **200**，返回真实应用（title 正确、演示页标记消失） |
| 公网静态资源 `/assets/*.js`、`/favicon.svg` | 200，content-type 正确 |
| 公网 SPA 深路由 | 200 且回 `index.html`（`try_files` 兜底生效） |
| 经网关 `/api/auth/login` | 通路正常 |

## 三、三个真实故障（详见 02-踩坑清单）

| # | 现象 | 根因 | 修法 |
|:-:|------|------|------|
| 1 | 手机上登录/注册报 **403 没有权限访问** | 后端 CORS 白名单没有公网域名 → 带 `Origin` 的 POST 被 Spring 直接 403 | 把域名加进 `CORS_ALLOWED_ORIGINS`，重启后端 |
| 2 | 头像/附件在手机上**裂图** | `MINIO_CUSTOM_DOMAIN` 写成了 `http://127.0.0.1:9000/...` | 改为同源相对路径 `/jwcfast`，并给桌面开发服务器补 `/jwcfast` 代理 |
| 3 | 前端 `npm run build` **构建失败** | `vite-plugin-pwa` 需要的 `workbox-window` 未在 package.json 声明 | `pnpm add -D workbox-window` |

**故障 1 的定位方法值得记住**（30 秒定性）：同一条请求，带 `Origin` 与不带 `Origin` 各发一次——
不带 200、带 403 空体 = **CORS 拒绝**，与业务逻辑无关。

## 四、经验沉淀

1. **"网页能开" ≠ "App 能用"**：WebView 会带 `Origin`，CORS、Cookie/SameSite、User-Agent 相关逻辑都可能与浏览器不同。
2. **远程 URL 模式让迭代极快**（改前端不用重发 APK），但代价是强依赖网络与服务在线；正式发布要重新评估。
3. **工具链都在非默认路径**时，最容易浪费时间的不是构建失败，而是"找不到 SDK/JDK"——所以本文档把路径写死在这里。
4. **国内网络一定要配镜像**：不配就是 2.4 小时 vs 2 分钟的区别。
